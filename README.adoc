= CloudBees workflow: Evaluate a policy

Use this reusable workflow to evaluate a policy and automatically route results to a manual approval flow when required.

The workflow runs the policy check and, if the result is `REQUEST_APPROVAL`, delegates to the CloudBees manual approval workflow before allowing the calling workflow to proceed.

== Inputs

[cols="2a,2a,2a,5a",options="header"]
.Input details
|===

| Input name
| Data type
| Required?
| Description

| `policy-id`
| String
| Yes
| The ID of the policy to evaluate.

| `input-data`
| String
| No
| Inline JSON data to pass into the policy evaluation as context.

| `input-file`
| String
| No
| Path to a file containing JSON data to pass into the policy evaluation as context.
Takes precedence over `input-data` when both are provided.

|===

== Outputs

[cols="2a,2a,5a",options="header"]
.Output details
|===

| Output name
| Data type
| Description

| `policy-action`
| String
| The action determined by policy evaluation.
Possible values are `CONTINUE`, `REQUEST_APPROVAL`, `BLOCK`, and `ERROR`.
`BLOCK` and `ERROR` results cause the workflow to exit with a non-zero status.
`REQUEST_APPROVAL` is handled internally by routing to a manual approval step; the output remains available to callers after approval is granted.

| `review-channel`
| String
| The channel type for review. Present only when `policy-action=REQUEST_APPROVAL`.

| `review-recipients`
| String
| The recipients for review. Present only when `policy-action=REQUEST_APPROVAL`.

|===

== Usage example

In the YAML file, all values are required, unless otherwise noted.

====

In your YAML file, add:

[source,yaml]
----
apiVersion: automation.cloudbees.io/v1alpha1
kind: workflow
name: my-workflow
on:
  workflow_dispatch:
permissions:
  scm-token-own: read
  scm-token-org: read
  id-token: write
jobs:
  build:
    outputs:
      scan-results: ${{ steps.scan.outputs.results }}
    steps:
      - id: scan
        name: Run scan
        # ... your build/scan steps here

  policy-evaluation:
    uses: cloudbees-io/policy-utils/workflow.yml@v1
    needs:
      - build
    with:
      policy-id: <your-policy-id>
      input-data: ${{ needs.build.outputs.scan-results }}

  deploy:
    needs:
      - policy-evaluation
    steps:
      - name: Deploy
        # ... steps that run only after policy evaluation passes
----
